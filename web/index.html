HOW TO MINE ARCMINER

1. Web & Mobile Mining (Easy) 📱

You don't need a high-end PC to mine ARCMINER. The Web Miner runs flawlessly on smartphones and laptops!

  • How it works: Simply open the website on your iPhone (Safari), Android (Chrome), or PC. Connect your wallet (MetaMask) and click "START MINING".
  • Hardware: Your device's processor will compute Keccak256 hashes in the background using JavaScript Web Workers.
  • Important for Mobile: Mobile operating systems will pause the browser if your screen turns off. To keep mining, you must leave the browser tab open and your phone's screen ON.

2. PRO Mining: Python CLI (GPU Support) 🖥️

For users with dedicated GPUs (NVIDIA/AMD/Intel) who want maximum Hashrate, we provide an advanced Python CLI Miner.

  • Step 1: Download the arcminer-cli.py script.
  • Step 2: Install Python dependencies by running:
    pip install web3 pyopencl
  • Step 3: Run the miner using:
    python arcminer-cli.py
  • Auto-Minting: When prompted, paste your private key. The CLI will automatically use PyOpenCL to blast through hashes on your GPU and submit the minting transaction immediately when a valid hash is found.
  • Security Note: Never share your private key. The CLI runs 100% locally on your machine.

3. Co-Op / Mining Pools (Team up!) 🤝

Want to multiply your hash rate? You can team up with friends to mine the same NFT faster!

  • The Shared Wallet Strategy: Create a brand new MetaMask wallet specifically for mining and fund it with some USDC for gas.
  • Distribute the Key: Share this new wallet's Private Key securely with your trusted friends.
  • Massive Hashrate: Everyone runs the `arcminer-cli.py` script on their own computers using that same Private Key. Your combined GPUs will all hunt for the exact same hash!
  • The Reward: When any of the computers finds the hash, the script will automatically mint the NFT into that shared wallet. You can then sell it and split the profits!

4. HOW MINING WORKS

ARCMINER uses a Proof-of-Work (PoW) mechanism using the Keccak256 algorithm. To mint an NFT, your machine must solve a cryptographic puzzle directly in your browser.

  • Algorithm: keccak256(abi.encodePacked(miner, nonce, prevWork, anchorHash))
  • Difficulty: The network dynamically adjusts the difficulty every 8 successful mints to target a 10-second mint pace.
  • Rarity: Your NFT's rarity depends on how "lucky" your hash is compared to the minimum required work.
    Common (+0..3 bits) | Rare (+4..7 bits) | Legendary (+8+ bits)

5. EPOCHS & PRICING

There is a strict maximum supply of 7,777 NFTs. The mint price increases as more NFTs are mined, divided into "Epochs".

  • Epoch 0: The first 8 mints cost exactly 1 USDC.
  • Later Epochs: The epoch size doubles each time (8, 16, 32, 64...). The price increases proportionally based on the ArcMiner tokenomics ratio.
  • Rent Distribution: 70% of the mint price is distributed to existing NFT holders as "Rent". 30% goes to the protocol treasury.

6. BURN & $ARCM TOKEN

ARCMINER NFTs can be burned to extract the underlying $ARCM protocol tokens.

  • Minimum Age: An NFT must be at least 10 minutes old before it can be burned.
  • Rewards: A fresh burn yields 1,000 $ARCM. Older NFT burn rewards decay based on how many epochs have passed since it was minted.
  • Liquidity Pool: You can instantly trade your $ARCM for USDC using the built-in decentralized swap pool on the "ARCM POOL" tab (2.5% fee).
